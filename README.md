# Proffy Web 2026 — Fluxo de Cadastro e Perfil do Professor

Plataforma web desenvolvida para conectar alunos e professores, construída no âmbito da disciplina de **Programação para Internet** (Curso de Sistemas de Informação — UEMG Unidade Ituiutaba).

Esta versão implementa o fluxo completo de **"Dar aulas"**, englobando o preenchimento do formulário de cadastro de professores, tela de confirmação de inscrição e a visualização e edição do perfil do usuário.

---

## 🚀 Como Rodar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- **Node.js** (versão 18 ou superior)
- **npm** (ou gerenciador compatível como yarn/pnpm)

### Passo a Passo para execução
1. Clone o repositório : https://github.com/Oliveirajon23/web-main
2. Instale as dependencias do projeto: npm install
3. Inicie o servidor de desenvolvimento do Vite: npm run dev
4. Abra o Navegador e acesse a URL que aparece no terminal: http://localhost:5173
